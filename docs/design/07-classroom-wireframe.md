# 07. 3x3 교실 UI 텍스트 와이어프레임

## 화면 목표

- 링크로 들어온 사용자가 첫 viewport에서 누구의 반인지와 현재 좌석표를 본다.
- 교실과 캐릭터가 가장 큰 시각적 비중을 차지한다.
- 참여 전, 참여 후, 만석 상태의 CTA가 한눈에 구분된다.
- 360px 너비에서도 9개 책상, 이름표, 관계 아이콘이 겹치지 않는다.

## 높이와 폭 규칙

```text
page max width: 520px
horizontal gutter: 16px (360px에서는 12px)
top bar height: 52px
classroom aspect ratio: 4 / 5
classroom max height: 560px
desk grid gap: clamp가 아닌 breakpoint 상수 6px / 8px
seat tap target: 최소 44x44 CSS px
```

폰트 크기를 viewport width에 비례해 연속 확대하지 않는다. 360~430px에서는 같은 typography scale을 쓰고, 359px 이하에서만 이름표 크기를 한 단계 줄인다.

## 교실 장면 계층

```text
ClassroomScene
  Background wall and floor
  Chalkboard band
    Clock
    Chalk title
  Window decoration
  Door decoration
  SeatGrid (3 columns x 3 rows)
    ClassroomSeat x 9
      CharacterSprite or EmptyDesk
      NamePlate
      RelationshipIcon
      OwnerBadge / NewBadge / SelectedOutline
  Low-priority props
    Plant
    Bookshelf
```

장식은 좌석 grid 밖 또는 뒤 레이어에 두며 캐릭터와 이름표를 가리지 않는다. 햇빛은 단색 반투명 면으로 제한하고 gradient 장식에 의존하지 않는다.

## 좌석 컴포넌트

```text
┌──────────────┐
│ 관계 아이콘   │  우측 상단, 16x16
│   캐릭터      │  고정 aspect ratio
│ ─── 책상 ─── │
│ 이름 최대 6자 │  한 줄 말줄임
└──────────────┘
```

- 생성자: 작은 분필 별 badge와 굵은 이름표
- 신규 참여자: 2초 이내의 outline pulse
- 선택됨: 캐릭터가 아닌 좌석 전체에 진한 outline
- 빈 좌석: 의자와 책상만 보이고 낮은 대비의 작은 점선 이름표
- 관계 아이콘은 색상 외에도 형태로 구분

## 첫 진입 순서

공유 링크로 들어오면 화면 상단부터 다음 순서로 읽힌다.

```text
재홍이네 반 / 4 of 9
교실 장면
전학 올래? 참여 폼
링크 공유 / 내 반 만들기
```

랜딩 설명이나 긴 관계 설명을 교실 위에 넣지 않는다.

## 좌석 상세 BottomSheet

책상 tap 시 화면 하단에서 올라온다.

```text
┌──────────────────────────────────┐
│                         [닫기 X] │
│      [민수 캐릭터]                │
│      민수                        │
│      재홍님의 뒷자리              │
│                                  │
│      공동피고인        [쪽지 icon] │
│      좋은 선택보다 재밌는 선택을   │
│      같이 할 가능성이 높은 사람.   │
│                                  │
│      집중력 -38%    재미 +92%     │
│                                  │
│      [내 자리 결과 공유하기]       │
│      [나도 내 반 만들어보기]       │
└──────────────────────────────────┘
```

- 높이는 콘텐츠에 맞추되 화면의 85%를 넘지 않는다.
- 배경 교실은 그대로 보여 현재 관계의 맥락을 유지한다.
- drag handle만으로 닫게 하지 않고 닫기 아이콘과 back 동작을 지원한다.

## 참여 입력 상태

### 기본

교실 아래에 인라인 폼을 보여준다. 실제 keyboard가 올라와도 제출 버튼을 볼 수 있도록 스크롤 여백을 둔다.

### 배치 중

폼 위치에 전체 화면 modal을 띄우지 않고 작은 진행 영역을 표시한다.

```text
[걷는 도트 캐릭터]
민수의 자리를 찾는 중...
책상을 살짝 옮기고 있어요.
```

교실은 계속 보이며 목표 좌석은 확정 전까지 강조하지 않는다.

### 배치 완료

문에서 목표 자리까지 1.8초 이내 이동 후 해당 좌석을 화면 중앙 가까이 스크롤하고 BottomSheet를 연다.

## 만석 상태

참여 폼을 아래 band로 교체한다.

```text
┌──────────────────────────────────┐
│ 우리 반 완성!                    │
│ 이 반은 이미 아홉 자리가 찼어요.  │
│                                  │
│ [교실 이미지 저장] [링크 공유]     │
│ [       나도 내 반 만들기       ] │
└──────────────────────────────────┘
```

기존 교실과 좌석 상세는 계속 탐색할 수 있다. 과한 confetti 대신 칠판 위 작은 분필 점과 600ms 흔들림 한 번만 사용한다.

## 오류 상태

교실 장면 자리에 오류 카드를 중첩하지 않고 페이지 내용을 교체한다.

```text
       [빈 교실 도트 장면]

       앗, 교실을 못 찾았어요.
       링크가 오래됐거나 잘못된 주소일 수 있어요.

       [내 반 만들기]
       [다시 시도]
```

네트워크 재시도에서는 입력값을 유지한다.

## 데스크톱

PC에서도 모바일 카드를 떠 있는 장식 card처럼 만들지 않는다. 배경 전체를 조용한 교실 벽 색으로 두고, 최대 520px의 콘텐츠 column을 중앙 정렬한다. 그림자보다 좌우 여백과 얇은 경계로 영역을 구분한다.

## 반응형 검수 항목

- 360x800: 교실 3열이 잘리지 않고 이름표가 책상 밖으로 나오지 않음
- 390x844: 교실과 참여 제목이 초기 viewport에 함께 보임
- 430x932: 교실이 불필요하게 확대되지 않고 다음 섹션 힌트가 보임
- 768px 이상: 최대 폭이 유지되고 CTA가 과도하게 늘어나지 않음
- 모바일 keyboard: 생년월일 입력과 제출 버튼으로 스크롤 가능
- text scale 200%: 주요 CTA와 이름이 겹치지 않고 교실 상세 접근 가능
