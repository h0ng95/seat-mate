# 04. 관계 유형 10개와 좌석 매핑

## 좌석 좌표

교실은 칠판을 위쪽, 창문을 왼쪽, 문을 오른쪽으로 본다.

```text
                 칠판

창문       0        1        2       문
           3        4        5
           6        7        8
```

- 행 `0`은 앞줄, 행 `2`는 뒷줄이다.
- 열 `0`은 창가, 열 `2`는 복도/문 쪽이다.
- 좌석 인덱스는 `row * 3 + column`이다.
- 생성자 자리는 성향 계산으로 결정하되, MVP 후보는 `1, 3, 4, 5, 7`을 우선해 주변 관계 좌석을 충분히 남긴다.

## 상대 위치 분류

생성자 `(ownerRow, ownerColumn)`와 후보 `(row, column)`의 차이를 사용한다.

```text
deltaRow = row - ownerRow
deltaColumn = column - ownerColumn
manhattan = abs(deltaRow) + abs(deltaColumn)
chebyshev = max(abs(deltaRow), abs(deltaColumn))
```

| 위치 | 조건 |
| --- | --- |
| 바로 옆 | `deltaRow == 0`, `abs(deltaColumn) == 1` |
| 바로 앞 | `deltaRow == -1`, `deltaColumn == 0` |
| 바로 뒤 | `deltaRow == 1`, `deltaColumn == 0` |
| 가까운 대각선 | `abs(deltaRow) == 1`, `abs(deltaColumn) == 1` |
| 같은 열 먼 자리 | `deltaColumn == 0`, `abs(deltaRow) >= 1` |
| 먼 자리 | `chebyshev >= 2` 또는 Manhattan 거리가 가장 큼 |

3x3 경계를 벗어나는 상대 위치는 후보에서 제거한다.

## 관계 정의

### 1. 찰떡 짝꿍 (`buddy`)

- 한 줄 설명: 말 안 해도 편하고, 붙어 있으면 하루가 금방 지나가는 관계.
- 관계 아이콘: 맞닿은 연필 두 자루
- 1순위: 생성자의 좌우 바로 옆
- 2순위: 가까운 대각선
- 3순위: Manhattan 거리 1인 자리

### 2. 수업 방해 공범 (`chatter`)

- 한 줄 설명: 둘이 붙어 있으면 집중력은 내려가고 재미는 올라가는 관계.
- 관계 아이콘: 말풍선 두 개
- 1순위: 뒤쪽 대각선
- 2순위: 바로 뒤
- 3순위: 같은 뒷줄

### 3. 정신적 반장 (`leader`)

- 한 줄 설명: 흔들릴 때 은근히 정신 차리게 만들어주는 사람.
- 관계 아이콘: 작은 칠판 별
- 1순위: 바로 앞
- 2순위: 앞쪽 대각선
- 3순위: 현재 가능한 자리 중 칠판에 가장 가까운 자리

### 4. 은근한 라이벌 (`rival`)

- 한 줄 설명: 평소에는 티가 안 나도 묘하게 의식하게 되는 관계.
- 관계 아이콘: 번개 모양 분필
- 1순위: 같은 열에서 가장 먼 자리
- 2순위: 같은 행의 반대쪽 끝
- 3순위: Manhattan 거리 2인 자리

### 5. 비상연락망 1순위 (`emergency`)

- 한 줄 설명: 자주 연락하지 않아도 필요할 때 가장 먼저 생각나는 사람.
- 관계 아이콘: 작은 전화 수화기
- 1순위: 가까운 대각선
- 2순위: 바로 앞 또는 바로 뒤
- 3순위: 좌우 바로 옆

### 6. 공동피고인 (`accomplice`)

- 한 줄 설명: 좋은 선택보다 재밌는 선택을 같이 할 가능성이 높은 사람.
- 관계 아이콘: 접힌 쪽지
- 1순위: 바로 뒤
- 2순위: 뒤쪽 대각선
- 3순위: 가장 뒤쪽의 빈 자리

### 7. 조용한 찐친 (`quiet_bestie`)

- 한 줄 설명: 자주 붙어 있지 않아도 어색하지 않은 오래가는 관계.
- 관계 아이콘: 닫힌 책
- 1순위: 생성자와 다른 행의 창가 자리
- 2순위: 창가 자리
- 3순위: 생성자와 Manhattan 거리 2 이상인 자리

### 8. 분위기 메이커 (`mood_maker`)

- 한 줄 설명: 갑자기 등장해 평범한 하루를 재미있게 만드는 사람.
- 관계 아이콘: 작은 확성기
- 1순위: 복도/문 쪽 자리
- 2순위: 뒷줄 자리
- 3순위: 생성자와 다른 행의 자리

### 9. 챙김 담당 (`caretaker`)

- 한 줄 설명: 말은 안 해도 이상하게 이것저것 챙겨주는 사람.
- 관계 아이콘: 우유 팩
- 1순위: 앞쪽 대각선
- 2순위: 바로 앞
- 3순위: 좌우 바로 옆

### 10. 예측불가 전학생 (`transfer`)

- 한 줄 설명: 가까운 듯 멀고, 멀어진 듯하다가 갑자기 가까워지는 관계.
- 관계 아이콘: 종이비행기
- 1순위: 생성자와 가장 먼 자리
- 2순위: 반대편 모서리
- 3순위: 남은 자리 중 seed 순위가 가장 높은 자리

## 후보 생성 규칙

각 관계 타입은 좌석 번호를 직접 하드코딩하지 않고 후보 점수 함수를 가진다.

```text
모든 좌석 0..8
  - 생성자 좌석 제거
  - 교실 경계 밖 제거
  - 관계별 위치 점수 계산
  - 같은 점수는 stable seed로 순서 결정
  - 이미 사용 중인 자리 제거
  - 첫 번째 자리 선택
```

관계별 선호가 모두 찬 경우에도 관계 타입은 바꾸지 않는다. 좌석만 전체 fallback 순서에서 결정하고, 상세 문구는 실제 좌석을 반영해 `재홍님의 대각선 자리`처럼 표시한다.

## 관계 선택 분포

stable hash 결과를 100칸 bucket으로 바꿔 다음과 같이 배정한다.

| 관계 | 범위 | 비율 |
| --- | ---: | ---: |
| buddy | 0~11 | 12% |
| chatter | 12~22 | 11% |
| leader | 23~31 | 9% |
| rival | 32~40 | 9% |
| emergency | 41~50 | 10% |
| accomplice | 51~61 | 11% |
| quiet_bestie | 62~71 | 10% |
| mood_maker | 72~81 | 10% |
| caretaker | 82~90 | 9% |
| transfer | 91~99 | 9% |

바이럴 핵심 문구인 `짝꿍`, `수업 방해 공범`, `공동피고인`을 합쳐 34%로 두고, 나머지는 과도한 편향 없이 분산한다.

## 재미용 수치

집중력과 재미 수치는 관계 타입의 기본 범위 안에서 별도 hash byte로 결정한다.

| 관계 | 집중력 | 재미 |
| --- | ---: | ---: |
| buddy | -10~20 | +70~95 |
| chatter | -55~-25 | +75~99 |
| leader | +45~80 | +20~55 |
| rival | +20~65 | +25~70 |
| emergency | +10~45 | +35~75 |
| accomplice | -60~-30 | +80~99 |
| quiet_bestie | +5~35 | +45~75 |
| mood_maker | -20~10 | +75~99 |
| caretaker | +30~70 | +35~70 |
| transfer | -35~35 | +40~95 |

이는 측정값이 아니라 오락용임을 결과 화면의 정보 구조와 문구 톤으로 명확히 한다.

## 충돌 처리 예시

생성자가 4번이고 `buddy`의 seed 정렬 결과가 `[5, 3, 2, 8, 0, 6, 1, 7]`이라고 가정한다.

```text
5번 비어 있음 -> 5번 배정
5번 사용 중, 3번 비어 있음 -> 3번 배정
5번과 3번 사용 중 -> 다음 선호인 2번 배정
모든 선호 사용 중 -> 공통 fallback의 첫 빈 자리 배정
```

DB의 `unique (classroom_id, seat_index)`와 참여 RPC 행 잠금이 동시 요청에서도 최종 충돌을 방지한다.
