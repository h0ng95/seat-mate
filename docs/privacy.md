# 개인정보 처리 원칙

`내 반에 앉아봐`는 재미용 관계 콘텐츠에 필요한 최소 정보만 처리한다.

## 수집하는 정보

- 사용자가 직접 입력한 이름 또는 별명
- 생년월일
- 입력으로 계산된 좌석, 관계 유형, 캐릭터 seed
- 교실 공유 코드와 생성 시각

## 수집하지 않는 정보

- 이메일, 전화번호, 주소
- 성별, 출생지, 학교 또는 지역
- 주민등록번호와 계정 비밀번호

실명 대신 별명을 사용할 수 있다. 생년월일은 결정론적 결과와 같은 교실의 중복 참여 확인에만 사용하며 공개 교실 조회 응답에는 포함하지 않는다.

## 공개 범위

공유 링크를 가진 사람은 교실의 별명, 좌석, 관계 유형, 캐릭터를 볼 수 있다. 생년월일과 정규화된 내부 비교값은 공개 view에서 제외한다.

## 보유와 삭제

MVP 출시 전 운영 환경에서 교실 만료 기간을 정한다. 기본 제안은 생성 후 90일이며, 만료된 교실과 구성원 데이터는 함께 삭제한다. 정식 서비스에서는 실제 운영 주체, 문의처, 보유 기간, 삭제 요청 방법을 명시한 개인정보 처리방침으로 교체한다.

## 주의

관계 문구와 집중력·재미 수치는 과학적 측정이나 사주 결과가 아닌 오락용 계산이다.
